# webui — interfaccia web per `rclone serve webdav`

Questo package aggiunge a `rclone serve webdav` l'interfaccia web di superdufs. La documentazione del fork
è in [`fork-doc/`](../fork-doc/README.md):

- [uso.md](../fork-doc/uso.md): avvio, flag, interfaccia, sicurezza, limiti noti;
- [sviluppo.md](../fork-doc/sviluppo.md): architettura, sincronizzazione con upstream e superdufs, test;
- [build.md](../fork-doc/build.md) e [ci-e-release.md](../fork-doc/ci-e-release.md): build, CI e release.
